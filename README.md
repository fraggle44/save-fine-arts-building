# Save the Fine Arts Building

Standalone public page for the Save the Fine Arts Building effort.

**Live page:** https://fraggle44.github.io/save-fine-arts-building/

## Publish model

Same pattern as the March Madness tracker:

- Static site files live in `docs/`
- GitHub Pages serves from branch `main`, folder `/docs`
- Update by replacing `docs/index.html` and pushing to `main`

## Source

Built from the standalone HTML bundle provided in the OpenClaw datatransfer drop.
